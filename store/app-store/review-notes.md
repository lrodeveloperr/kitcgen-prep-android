# App Review notes — Kitchen Prep Board 2.0.0

Kitchen Prep Board is a paid-upfront, ad-free, local-first kitchen workflow utility.

- No account, login, demo credentials, external hardware or server connection is required.
- The app contains no in-app purchases, subscriptions, advertising or analytics on iOS.
- User-created boards, templates and settings remain on the device.
- Notifications are optional and are used only for user-created local timers.
- `ITSAppUsesNonExemptEncryption` is `false`; the app does not implement proprietary encryption.
- The app provides workflow organization, not food-safety advice.

Suggested review path:

1. Open **New**.
2. Name a board and add two or more prep tasks.
3. Set a duration or dependency, then review and start the board.
4. Open the live board to test Now / Waiting / Next / Done, pause/resume and timer behavior.
5. Open **Settings** to verify language, unit, temperature, notification, keep-awake and local-data controls.
